# Sound_play #
ini adalah aplikasi android untuk anak-anak dibawah 3 tahun untuk mengetahui bunyi-bunyian seperti Hewan, Kendaraan atau  alat musik lainnya. 
fitur yang ada, ada 3 posisi untuk melihat gambar hewan, kendaraan atau alat musik dan ada tombol play untuk mendengarkan bunyi-bunyian tersebut.

tugas 
1. buatlah aplikasi android menggunakan bahasa pemrograman java 
2. buat ambil atau ubah dari suara referensi non komersil di web untuk mendengarkan suaranya.
3. buat tampilannya yang kids friendly
4. buat setiap suara harus menampilkan gambar dari hewan, kendaraan atau alat musik
5. setiap kategori ada 10 gambar hewan, kendaraan atau alat musik.
